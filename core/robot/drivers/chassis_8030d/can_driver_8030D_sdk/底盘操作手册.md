# 底盘操作手册

本文档仅涵盖轮子（电机）的操作方法，包括使能、速度控制、速度回读和停止。

---

## 前置条件

- 硬件已按接线说明正确连接（CAN 总线、电源、电机 U/V/W 相线）
- CAN 驱动器节点已启动：

```bash
ros2 launch can_driver can_driver_8030.launch.py
```

---

## 1. 电机使能（上电）

轮子运转前必须先使能电机。使能分为三步上电序列，由驱动器自动完成。

### ROS 2 方式

发布使能命令到 `/driver` 话题：

```bash
ros2 topic pub --once /driver std_msgs/msg/Int8 "{data: 1}"
```

> **配置说明**：如果启用了 `auto_enable_on_start: true`（默认配置），节点启动后电机会自动使能，无需手动发送此命令。

### 直接 CAN 方式

依次发送以下三帧（CAN ID: `0x601`）：

| 步骤 | CAN 数据帧 (8 字节) | 说明 |
|------|---------------------|------|
| 1 | `2B 40 60 00 06 00 00 00` | Shutdown |
| 2 | `2B 40 60 00 07 00 00 00` | Switch on |
| 3 | `2B 40 60 00 0F 00 00 00` | Enable operation |

> 每一步之间建议间隔 10~50 ms，等待驱动器状态切换完成。

## 2. 设置轮子速度

### ROS 2 方式

发布速度命令到 `/motor_speed` 话题，数据格式为 `[右轮速度, 左轮速度]`，单位 **RPM**。

**示例**：

```bash
# 双轮前进 100 RPM
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [100, 100]}"

# 左转（右轮快、左轮慢）
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [150, 50]}"

# 右转（右轮慢、左轮快）
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [50, 150]}"

# 原地旋转（右轮反转、左轮正转）
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [-100, 100]}"

# 后退
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [-100, -100]}"

# 停止
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [0, 0]}"
```

**参数说明**：
- `data[0]` = 右轮速度，`data[1]` = 左轮速度
- 数值范围：`-256 ~ 256` RPM（由 `motor_speed_max` 参数配置，默认 256）
- 正值：电机正转（前进方向）
- 负值：电机反转（后退方向）
- 左右轮独立控制，差速实现转向

### 持续控制（非单次）

如需持续控制，去掉 `--once` 参数并指定发布频率：

```bash
# 以 20 Hz 持续发送 100 RPM 的前进命令
ros2 topic pub /motor_speed std_msgs/msg/Int16MultiArray "{data: [100, 100]}" -r 20
```

> 按 `Ctrl+C` 停止发布。注意：停止发布后电机会保持最后一次收到的速度指令，需手动发送 `[0, 0]` 停止。

### 直接 CAN 方式

**CAN ID**: `0x601`

| Byte | 值 | 说明 |
|------|-----|------|
| 0 | `0x23` | 写 4 字节命令 |
| 1 | `0xFF` | Object 低字节 |
| 2 | `0x60` | Object 高字节 (0x60FF = Target Velocity) |
| 3 | `0x03` | Sub-index（同步模式） |
| 4 | speed_L | 右电机速度低字节 |
| 5 | speed_H | 右电机速度高字节 |
| 6 | speed_L | 左电机速度低字节 |
| 7 | speed_H | 左电机速度高字节 |

速度值为 16 位有符号整数（二进制补码），单位 RPM。

**示例**（右 100 RPM，左 50 RPM）：

```
23 FF 60 03 64 00 32 00
```

**负速度示例**（右 -100 RPM，左 50 RPM）：

```
23 FF 60 03 9C FF 32 00
```

> 说明：-100 的 16 位补码为 `0xFF9C`，低字节在前 → `9C FF`

## 3. 读取轮子当前速度

### ROS 2 方式

监听 `/current_speed` 话题获取速度反馈：

```bash
ros2 topic echo /current_speed
```

输出示例：

```
data:
- 98
- 52
---
```

其中 `data[0]` 为右轮当前速度，`data[1]` 为左轮当前速度，单位 **0.1 RPM**（即 98 表示 9.8 RPM）。

### 直接 CAN 方式

**请求帧**（CAN ID: `0x601`）：

```
40 6C 60 03 00 00 00 00
```

**应答帧**（CAN ID: `0x581`）：

| Byte | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|---|
| 值 | `0x43` | `0x6C` | `0x60` | `0x03` | L_speed_L | L_speed_H | R_speed_L | R_speed_H |

**速度计算**：
- 原始值 ≤ 10000 → 直接使用
- 原始值 > 10000 → 负值 = 原始值 - 65536
- 单位：0.1 RPM

## 4. 读取轮子线速度/角速度（扩展帧）

驱动器以扩展帧自动广播整车速度数据，无需请求。

**CAN ID**: `0xCFF5188`（扩展帧）

| Byte | 0 | 1 | 2 | 3 |
|------|---|---|---|---|
| 含义 | V_L | V_H | W_L | W_H |

计算方式：

```
线速度 v = ((V_H × 256 + V_L) - 32768) / 1000   (m/s)
角速度 w = ((W_H × 256 + W_L) - 32768) / 1000   (rad/s)
```

## 5. 停止 & 失能

### 正常停止

发送零速度指令即可停车：

```bash
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [0, 0]}"
```

### 紧急停止 / 失能

失能命令会切断电机使能，电机自由滑行（无制动力）：

```bash
ros2 topic pub --once /driver std_msgs/msg/Int8 "{data: 0}"
```

### 直接 CAN 方式 — 失能

**CAN ID**: `0x601`，发送：

```
2B 40 60 00 00 00 00 00
```

## 注意事项

1. **必须先使能再发速度**：电机未使能时速度命令不生效。
2. **速度范围**：默认最大 ±256 RPM，超出部分会被截断到 `motor_speed_max` 配置值。
3. **停车 ≠ 失能**：发送 `[0, 0]` 仅让电机停止转动，电机仍处于使能状态（保持力矩）；失能后电机自由转动。
4. **紧急情况**：优先使用紧急失能命令 `{data: 0}` 切断动力。
5. **持续发送场景**：如果以 `-r` 持续发送速度，务必确保程序退出前发送一次 `[0, 0]` 停车。
