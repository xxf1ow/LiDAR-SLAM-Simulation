# 硬件接线说明

## 系统连接图

```
┌─────────────┐     USB      ┌─────────────┐     CAN H/L     ┌──────────────┐    电源线    ┌──────┐
│  Jetson     │──────────────▶│  USBCAN2    │────────────────▶│  8030D 驱动  │──────────▶│ 电机 │
│  Orin/Nano  │               │  适配器     │                 │  器 (x2)     │           │      │
└─────────────┘               └─────────────┘                 └──────────────┘           └──────┘
                                                                     │
                                                                     ├─ CAN H ──┬─ 120Ω ──┤
                                                                     │          │ 终端电阻 │
                                                                     ├─ CAN L ──┘          │
                                                                     │                      │
                                                                     ├─ 24V/48V DC 电源 ───┘
                                                                     ├─ 电机 U/V/W 相线
                                                                     └─ 霍尔传感器线 (可选)
```

---

## 1. ZLG USBCAN2 适配器

### 接口定义

| 引脚 | 信号 | 连接目标 |
|------|------|----------|
| CAN1_H | CAN 高 | 8030D 驱动器 CAN_H |
| CAN1_L | CAN 低 | 8030D 驱动器 CAN_L |
| CAN2_H | CAN 高（可选） | 第二路 CAN 设备 |
| CAN2_L | CAN 低（可选） | 第二路 CAN 设备 |
| USB | USB 2.0 | Jetson USB 口 |

### 注意事项

- CAN 总线两端必须各接入 **120Ω 终端电阻**（CAN_H 和 CAN_L 之间）
- 推荐使用屏蔽双绞线
- 总线长度建议不超过 40 米（500Kbps 下）
- 多个设备以菊花链方式并联在总线上

---

## 2. ZL-8030D 电机驱动器

### 电源接线

| 驱动器端子 | 连接 | 说明 |
|-----------|------|------|
| VCC | 电源正极 | 24V 或 48V DC（根据电机规格） |
| GND | 电源负极 | — |

### CAN 总线接线

| 驱动器端子 | 连接 |
|-----------|------|
| CAN_H | USBCAN2 CAN1_H |
| CAN_L | USBCAN2 CAN1_L |

> **注意**：两个 8030D 驱动器并接在同一 CAN 总线上即可。

### 电机接线

| 驱动器端子 | 电机线 | 颜色参考 |
|-----------|--------|----------|
| U | 电机 U 相 | 黄 |
| V | 电机 V 相 | 绿 |
| W | 电机 W 相 | 蓝 |
| HU/HV/HW | 霍尔传感器（可选） | — |
| GND | 霍尔传感器 GND | — |
| +5V | 霍尔传感器供电 | — |

---

## 3. 终端电阻

CAN 总线两端必须各接入一个 **120Ω / 0.25W** 终端电阻：

- 近 USBCAN2 端：在 CAN1_H 和 CAN1_L 之间接 120Ω
- 远端：在最后一个 8030D 驱动器的 CAN_H 和 CAN_L 之间接 120Ω

**如果只有 2 个 8030D 驱动器**，USBCAN2 接一端，最远的驱动器接另一端即可。

---

## 4. 供电要求

| 项目 | 规格 |
|------|------|
| 驱动器供电 | DC 24V ~ 48V |
| 额定功率 | 取决于电机规格（8030D 最大 300W） |
| Jetson 供电 | 独立供电，建议使用官方电源适配器 |

> **警告**：请勿将电机驱动电源与 Jetson 电源共用，以免电机干扰导致 Jetson 重启。

---

## 5. USB 设备识别

连接 USBCAN2 后，在 Jetson 上执行：

```bash
lsusb
# 应能看到 ZLG 相关设备（VID 通常为 04D8）

dmesg | tail -10
# 查看内核识别日志
```

如设备未被识别，请确认 udev 规则已正确配置：

```bash
cat /etc/udev/rules.d/99-zlg-usbcan2.rules
# SUBSYSTEM=="usb", ATTR{idVendor}=="04d8", ATTR{idProduct}=="0053", MODE="0666"
```

---

## 6. 检验清单

上电前请逐项确认：

- [ ] CAN 总线两端已接入 120Ω 终端电阻
- [ ] CAN_H 和 CAN_L 未反接
- [ ] 驱动器供电电压在额定范围内
- [ ] 电机 U/V/W 相线牢固连接
- [ ] Jetson 与 USBCAN2 的 USB 连接正常
- [ ] 电机供电与 Jetson 供电隔离
