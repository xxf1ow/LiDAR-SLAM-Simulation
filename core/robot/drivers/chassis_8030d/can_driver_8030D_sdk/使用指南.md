# CAN Driver 8030D SDK — 介绍

## 概述

CAN Driver 8030D SDK 是一套面向 **ZL-8030D 电机驱动器**的 ROS 2 驱动软件包。它通过 **ZLG USBCAN2** CAN 总线适配器与驱动器通信，实现对双路直流无刷轮毂电机的速度控制、状态回读及辅助功能（转向灯、顶升、称重等）。

**适用平台**：NVIDIA Jetson Orin / Jetson Nano + JetPack 6 + Ubuntu 22.04 (arm64)

## 功能列表

| 功能 | ROS 2 话题 | 说明 |
|------|-----------|------|
| 电机使能/失能 | `/driver` | `Int8`，1 = 使能，0 = 失能 |
| 轮子速度控制 | `/motor_speed` | `Int16MultiArray`，`[右轮, 左轮]`，单位 RPM |
| 当前速度回读 | `/current_speed` | `Int16MultiArray`，`[右轮, 左轮]`，单位 0.1 RPM |
| 母线电压读取 | `/current_voltage` | `Int16`，原始 ADC 值 |
| 称重传感器 | `/current_weight` | `Int16`，原始 ADC 值 |
| 转向灯控制 | `/light` | `Int8`，0 = 灭，4 = 右转，8 = 左转 |
| 顶升控制 | `/lift` | `Int8`，1 = 降，2 = 升 |

## 安装步骤

### 1. 确认系统环境

```bash
# 检查 JetPack / L4T 版本
cat /etc/nv_tegra_release
# 应输出类似: R36.x (JetPack 6)

# 检查 Ubuntu 版本
lsb_release -a
# 应输出: Ubuntu 22.04.x LTS

# 检查架构
uname -m
# 应输出: aarch64

# 检查 ROS 2 Humble
source /opt/ros/humble/setup.bash
ros2 --version
```

### 2. 运行一键安装脚本

```bash
cd can_driver_8030D_sdk
chmod +x scripts/setup_jetson.sh
./scripts/setup_jetson.sh
```

脚本会自动完成：
- 检查 ROS 2 和 JetPack 版本
- 安装 libusb 等系统依赖
- 部署 libcontrolcan.so 到 `/usr/local/lib/`
- 配置 ZLG USBCAN2 的 udev 规则
- 构建 ROS 2 工作空间

### 3. 验证安装

```bash
# 加载工作空间
source ~/can_ws/install/setup.bash

# 查看节点是否可运行
ros2 run can_driver can_driver_8030 --help
```

## 快速开始

```bash
# 1. 启动 CAN 驱动节点
ros2 launch can_driver can_driver_8030.launch.py

# 2. 使能电机（若未开启 auto_enable_on_start）
ros2 topic pub --once /driver std_msgs/msg/Int8 "{data: 1}"

# 3. 发送速度指令（前进 100 RPM）
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [100, 100]}"

# 4. 查看当前速度
ros2 topic echo /current_speed

# 5. 停车
ros2 topic pub --once /motor_speed std_msgs/msg/Int16MultiArray "{data: [0, 0]}"
```

## 配置参数

所有参数在 `config/can_driver_params.yaml` 中集中管理，启动时可通过命令行覆盖：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `can_device_type` | 4 | CAN 设备类型（4 = USBCAN2） |
| `can_device_index` | 0 | 设备编号 |
| `can_channel` | 0 | CAN 通道（0 = CAN1，1 = CAN2） |
| `can_timing0` | 0x00 | 波特率时序寄存器 0（500Kbps） |
| `can_timing1` | 0x1C | 波特率时序寄存器 1（500Kbps） |
| `motor_speed_max` | 256 | 最大速度限制 (RPM) |
| `auto_enable_on_start` | true | 启动时自动使能电机 |
| `speed_ask_interval` | 0.05 | 速度查询间隔 (秒) |

命令行覆盖示例：

```bash
ros2 launch can_driver can_driver_8030.launch.py motor_speed_max:=300
```

## 通信协议

与驱动器之间采用 **CANopen 兼容协议**，帧类型为标准帧（11-bit ID）与扩展帧（29-bit ID）混合：

| 通信类型 | CAN ID | 说明 |
|----------|--------|------|
| SDO 请求 | `0x601` | 主控 → 驱动器（速度/使能/电压） |
| SDO 应答 | `0x581` | 驱动器 → 主控 |
| 转向灯/顶升 | `0x01AF` | 标准帧控制 |
| 称重数据 | `0x03BF` | 驱动器主动上报 |
| 模拟量采集 | `0x0181`, `0x0281` | ICAN 模块数据 |
| 车速数据 | `0xCFF5188` | 扩展帧（整车 v/w） |

## 技术指标

| 项目 | 指标 |
|------|------|

| CAN 总线终端电阻 | 120Ω（总线两端各一） |
| 总线推荐长度 | ≤ 40m（500Kbps 下） |
