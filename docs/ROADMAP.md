# ROADMAP — 长期规划

差速机器人在工厂先验图里自主作业的**产品级系统**。当前：算法主线（FAST-LIO 里程计 + GICP 先验图定位 + Nav2 自主导航）已端到端打通，处于"**可用，待加固为产品级**"阶段。

> 本文是**方向指引 + todo 清单**，不写实现细节。具体实现设计见各模块 `README.md`，架构与仿真 gotchas 见 [`CLAUDE.md`](../CLAUDE.md)。

## 一、产品愿景（完成时能做到什么）

给定一个目标位姿，机器人在工厂先验图里自主规划并开到目标；沿途识别并避让动态障碍；遇到失效（定位丢失、传感器掉线、碰撞风险）时安全减速或停车；全程健康状态与性能指标可观测、故障可排查、日志可回放；同一套代码与配置可切换部署到真机。

产品级系统的硬指标维度：

- **安全**：传感器级避撞保护、急停、限速、禁行区。
- **可靠**：失效能告警并安全停车；启动与停机有序、不残留进程。
- **可运维**：健康/性能指标可见，故障可排查，数据可录制回放。
- **可落地**：同一套代码/配置可切到真机运行。
- **可交付**：有任务下发接口、可容器化部署、有回归测试。

## 三、待完成事项

状态：`- [ ]` 未开始 / `- [x]` 已完成；**已知问题**项在条目末尾注明根因，以区别于纯未开始。

### A. 安全与失效保护（产品级最低线）

- [ ] `collision_monitor`：独立于规划器的传感器级避撞/减速/急停。
- [ ] `velocity_smoother`：限制 jerk/加速度，保护机械结构与负载。
- [ ] 急停（e-stop）+ `twist_mux`：多路 cmd_vel 优先级抢占，手动 teleop 与 nav 复用。
- [ ] costmap filters：禁行区、限速区。

### B. 系统可靠性与可运维性

- [ ] managed lifecycle 启动 + 优雅停机 — **已知问题**：当前启动靠 `TimerAction` 硬延迟错峰、停机靠手动按进程组 kill；孤儿进程与 OOM 是反复出现的运维痛点（见 `CLAUDE.md` "Running the sim stack" 一节）。
- [ ] 全局 diagnostics（现仅 gicp_localization 有编译期诊断）。
- [ ] 健康告警：定位丢失、fitness 跌落、传感器掉线、`/clock` 跳变、TF 断链。
- [ ] 指标采集：RTF、CPU/内存、话题 hz、TF 延迟的持续记录。
- [ ] rosbag2 标准化录制/回放 profile。
- [ ] runbook 运维手册（基于现有 FAIL 排查扩写）。

### C. 导航能力补全

- [x] 动态障碍层（静态堵路已解）：全局+局部 costmap 均用 STVL 实时障碍层（源 `/cloud_registered`），全局规划器看到新障碍即绕行。**残留**：运动障碍（行人）避让 + 预测式 MPPI 仍为独立里程碑（需先建动态障碍仿真包）。
- [ ] waypoint/穿点导航：启用 `waypoint_follower`（`navigate_through_poses` 已可用）。
- [ ] 恢复行为增强（现为基础 spin/backup/wait）。
- [ ] 近场盲区擦障碍修复（U 形死路绕行撞墙） — **已知问题**：转向贴近长条障碍时，雷达近场盲区（FAST-LIO `blind=1.0`）内已观测的 voxel 段被 STVL 视锥清除，局部 costmap 出现假缺口，MPPI 钻缺口撞墙；根因为近场盲区 + 视锥清除擦除已知障碍（绕行本身正确），方向=缩 `blind` / 盲区保形 / `collision_monitor` 兜底。
